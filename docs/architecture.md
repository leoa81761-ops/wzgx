# 生成管线

对照当前 main 上的 `pipeline.Build`。一篇文章从写作计划长出来，额度记在用户上，公众号和计划必须属于同一个用户。

## 归属

| 数据 | 归属 | 失败时 |
| --- | --- | --- |
| 每日额度、周期额度、加量包、订单 | 用户 | 额度用完会暂停计划，原因是「额度已用完」。支付回调只给订单上的用户加权益 |
| 公众号、语气、口头禅、栏目 | 公众号 | 解绑或授权失效会暂停指向它的计划 |
| 方向、节奏、篇幅、选题 | 计划 | 计划必须指向自己用户名下的号。对不上就暂停，原因是「账号不匹配」，并且不会建任务 |
| 文章、任务 | 计划，同时记下用户和公众号 | 同一计划同时只能有一个未完成任务 |

定时扫描按计划的下次运行时间取任务。手动生成和重写可以在计划暂停时进行，定时生成不行。

## 阶段

`Build` 按下面的顺序走。某一阶段的模型调用失败时，任务记失败，不写草稿。检索失败不中断，改走经验分享。

| 阶段 | 输入 | 输出 | 失败 |
| --- | --- | --- | --- |
| 选题 | 方向、栏目定位、人设（语气、口头禅、读者）、最近标题 | 一个题和角度 | 模型无合法 JSON 则任务失败。和最近题目撞车会再要一次，仍撞车就换一个没用过的子题 |
| 资料检索 | 题、屏蔽域名、用户的 Tavily 钥匙 | 带来源网址的事实，或空 | 模型联网搜索，最多约 20 秒（grok-chat-fast）或 60 秒。不够两条可用来源时不报错，写作模式改成经验分享。SearXNG 默认关闭 |
| 大纲 | 题、栏目结构、篇幅参考 | 各节标题和这一节要写完的事 | 模型失败则任务失败。标题必须带上题目里的对象，重复标题会被丢掉 |
| 正文 | 大纲里的一节 | 这一节的段落 | 按节写。某一节失败则任务失败。写完后如果正文被清空，用已经拼好的那一版 |
| 敏感词 | 正文和全站敏感词、这个号不写的说法 | 改过的正文，或失败 | 先改一次。仍有敏感词则任务失败，不写草稿。润色后再查一次 |
| 润色 | 正文 | 开头和结尾可能被改过的正文 | 只做一轮。时间不够就跳过。不扩写，也不为了字数去缩 |
| 标题 | 正文、摘要、最近标题 | 一个标题和备选 | 模型失败就留原稿标题。和摘要或正文对不上、或标题里的数字正文没有，会被丢掉 |
| 定稿 | 上面的草稿 | HTML | 见下面的闸门。闸门拦住时文章仍保存，但不写入公众号草稿 |

经验分享不再调用模型补字。本地会去掉编造的引用、暖场空话，并要求留下能照做的做法。

## 闸门

这些条件会留下文章，但不写入公众号草稿：

| 标记 | 含义 |
| --- | --- |
| 无参考来源 | 付费档检索过，却没有可用来源，也不是经验分享 |
| 快报没有日期 | 快报栏目没有带日期的来源，又没有别的栏目可换 |
| 正文是空的 | 各节都没有字 |
| 没有引用 | 有来源，正文却对不上这些来源 |
| 栏目结构对不上 | 问答、步骤或快报的模板没写出来 |
| 经验太空 | 经验分享里能照做的做法太少，而且空话多 |
| 正文在重复 | 同一句反复出现，或把题目嵌进套话 |

篇幅不是闸门。`word_target` 只写进大纲，当作这一节大概写多长。短稿会发出去。

## 已经删掉的路径

扩写和缩写不再进入 `Build`。模型提示词里也不再有这两步。正文偏短或偏长都保持模型写出的那一版，不再追加小节，也不再压到某个字数。
